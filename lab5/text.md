```python
img1 = cv2.imread('image1.jpg')
img2 = cv2.imread('image2.jpg')

img1_gray = cv2.imread('image1.jpg', cv2.IMREAD_GRAYSCALE)
img2_gray = cv2.imread('image2.jpg', cv2.IMREAD_GRAYSCALE)
```
- **Строки 5–6 (`cv2.imread('image1.jpg')`, `cv2.imread('image2.jpg')`):**
  - Функция `cv2.imread(filename[, flags])` считывает изображение с диска.
  - По умолчанию второй аргумент равен `cv2.IMREAD_COLOR` (числовой эквивалент `1`), что означает загрузку трехканального цветного изображения с глубиной 8 бит на канал.
  - **Важная особенность OpenCV:** каналы считываются в порядке **BGR (Blue, Green, Red)**, а не привычном RGB. Массив имеет трехмерную форму `(высота, ширина, 3)`.
  - `img1` — эталонное изображение логотипа (на белом фоне).
  - `img2` — сцена (фотография реального документа, на котором требуется найти логотип).
- **Строки 8–9 (`cv2.imread(..., cv2.IMREAD_GRAYSCALE)`):**
  - Флаг `cv2.IMREAD_GRAYSCALE` (числовой эквивалент `0`) принудительно преобразует изображение при чтении в одноканальное полутоновое (градации серого) по формуле яркости ITU-R BT.601:  
    $$Y = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$
  - Получаемый массив имеет двумерную форму `(высота, ширина)` и тип данных `uint8` (значения яркости от 0 — черный до 255 — белый).
  - **Зачем это нужно:** алгоритмы локальных дескрипторов (включая SIFT) анализируют градиенты пространственной интенсивности (перепады яркости). Цветовые каналы несут избыточную вычислительную нагрузку (в 3 раза больше данных) и могут приводить к ложным откликам из-за цветового шума освещения.

Если далее попытаться вызвать свойства `.shape` или передать `None` в алгоритм SIFT, программа упадет с непонятной внутренней ошибкой C++ ядра (`error: (-215:Assertion failed)`).

```python
def show_image(images, titles, figsize=(15, 5)):
    if not isinstance(images, (list, tuple)):
        images = [images]
    if not isinstance(titles, (list, tuple)):
        titles = [titles]

    fig, axes = plt.subplots(1, len(images), figsize=figsize)

    if len(images) == 1:
        axes = [axes]

    for ax, image, title in zip(axes, images, titles):
        if image.ndim == 2:
            ax.imshow(image, cmap='gray')
        else:
            ax.imshow(cv2.cvtColor(image, cv2.COLOR_BGR2RGB))

        ax.set_title(title)
        ax.axis('off')

    plt.tight_layout()
    plt.show()
```
- **Строки 14–36:** Пользовательская универсальная функция отрисовки изображений:
  - `images`: одно изображение или список изображений для вывода.
  - `titles`: заголовок или список заголовков для каждого графика.
  - `figsize=(15, 5)`: кортеж ширины и высоты общего полотна в дюймах.
  - `isinstance(..., (list, tuple))`: приводит одиночный переданный объект к списку из одного элемента, гарантируя единообразную итерацию.
  - `plt.subplots(1, len(images), figsize=figsize)`: создает фигуру `fig` и одномерный массив осей `axes` с количеством столбцов, равным числу отображаемых изображений.
  - `if len(images) == 1: axes = [axes]`: когда рисуется только один график, `plt.subplots` возвращает одиночный объект `AxesSubplot`, а не массив. Оборачивание в список позволяет безопасно применять цикл `zip`.
  - `for ax, image, title in zip(...)`: параллельный проход по осям, массивам пикселей и подписям.
  - `if image.ndim == 2`: проверка размерности массива NumPy. Если `ndim == 2`, перед нами полутоновое изображение `(H, W)`.
  - `ax.imshow(image, cmap='gray')`: отрисовка одноканального кадра. Параметр `cmap='gray'` критически важен: по умолчанию Matplotlib отображает одноканальные матрицы в псевдоцветах палитры `'viridis'` (от темно-синего до желтого).
  - `cv2.cvtColor(image, cv2.COLOR_BGR2RGB)`: конвертация трехканального изображения из формата BGR (OpenCV) в RGB (Matplotlib). Без этой операции красный и синий каналы поменяются местами (лица станут синими, небо — коричневым).
  - `ax.set_title(title)`: добавление понятной подписи сверху над изображением.
  - `ax.axis('off')`: отключение отображения пиксельных координат и рамки осей, обеспечивая аккуратный вид.
  - `plt.tight_layout()`: автоматическое выравнивание отступов между графиками во избежание наложения заголовков.
  - `plt.show()`: принудительная отрисовка фигуры в выводе ячейки блокнота.

## БЛОК 2. Ячейка 5 — Задание 2: Детекция SIFT и извлечение дескрипторов


- **Строка 1:** Создание экземпляра детектора и дескриптора **SIFT** (`Scale-Invariant Feature Transform`).
- **Как устроен SIFT изнутри:**
  1. **Построение масштабного пространства (Scale-space):** исходное изображение последовательно сглаживается фильтрами Гаусса с разным масштабом $\sigma$ и уменьшается в размере (образуются октавы).
  2. **Разность гауссианов (DoG — Difference of Gaussians):** вычитание соседних сглаженных изображений для аппроксимации лапласиана гауссиана (LoG):
     $$D(x, y, \sigma) = L(x, y, k\sigma) - L(x, y, \sigma)$$
  3. **Поиск экстремумов:** каждая точка сравнивается со своими 8 соседями на текущем масштабе и по 9 соседями на слоях выше и ниже (всего 26 точек в кубе $3 \times 3 \times 3$).
  4. **Уточнение ключевых точек:** отбрасываются точки с низким контрастом (параметр `contrastThreshold=0.04`) и точки на прямолинейных ребрах через анализ собственных значений матрицы Гессе (параметр `edgeThreshold=10`).
  5. **Назначение ориентации:** вычисляются градиенты в окрестности точки и строится гистограмма ориентаций с шагом 10 градусов (36 бинов). Доминантный пик определяет угол точки $\theta$, обеспечивая инвариантность к повороту.
  6. **Построение 128-мерного дескриптора:** вокруг точки берется область $16 \times 16$ пикселей, разбивается на 16 подблоков $4 \times 4$. В каждом подблоке строится 8-биновая гистограмма ориентаций градиентов. Итог: $4 \times 4 \times 8 = 128$ вещественных чисел. Вектор нормализуется на единичную длину (L2-норма), что дает инвариантность к изменению яркости и контраста.
- Параметры конструктора `cv2.SIFT_create()` по умолчанию:

  - `edgeThreshold=10` (порог отношения кривизн для отсечения контурных линий).
  - `sigma=1.6` (начальное гауссово размытие).

## БЛОК 3. Ячейка 7 — Задание 3: Первичное сопоставление через BFMatcher

```python
bf = cv2.BFMatcher(cv2.NORM_L2, crossCheck=False)
```
- **Строка 1:** Инициализация сопоставителя **Brute-Force Matcher** (`cv2.BFMatcher`):
  - Алгоритм полного перебора: для каждого вектора из первого набора перебирает все векторы из второго набора и вычисляет метрику расстояния между ними.
  - Параметр `normType=cv2.NORM_L2`: метрика расстояния между дескрипторами. Поскольку SIFT генерирует вещественные векторы градиентов, эталонной метрикой сходства является **евклидово расстояние**:
    $$L_2(u, v) = \sqrt{\sum_{i=1}^{128} (u_i - v_i)^2}$$
    *(Для бинарных дескрипторов, например ORB/BRIEF, использовалась бы метрика `cv2.NORM_HAMMING`).*
  - Параметр `crossCheck=False`: отключение взаимной перекрестной проверки. Если включить `crossCheck=True`, алгоритм возвращает только такие пары $(A, B)$, где $B$ — ближайший к $A$, а $A$ — одновременно ближайший к $B$. В нашем пайплайне перекрестная проверка отключена, поскольку на следующем этапе мы будем применять более гибкий и строгий критерий Дэвида Лоу через `knnMatch(k=2)`.


## БЛОК 4. Ячейка 9 — Задание 4: Фильтрация по критерию Дэвида Лоу (Lowe's Ratio Test)

```python
matches_knn = bf.knnMatch(des1, des2, k=2)
```
- **Строка 1:** Метод `bf.knnMatch(des1, des2, k=2)`:
  - Ищет **$k=2$ ближайших дескриптора** в `des2` для каждого дескриптора из `des1`.
  - Возвращает список списков вида `[[m_0, n_0], [m_1, n_1], ...]`, содержащий 126 пар.
  - В каждой паре `m` — первый ближайший сосед (наименьшее расстояние $d_1$), а `n` — второй ближайший сосед (следующее расстояние $d_2$, где $d_2 \ge d_1$).

```python
ratio_threshold = 0.75
good_matches = []

for m, n in matches_knn:
    if m.distance < ratio_threshold * n.distance:
        good_matches.append(m)
```
- **Строки 3–8:** Реализация критерия отношения расстояний (Lowe's Ratio Test):
  - **Математическая логика:** Если признак на сцене уникален, расстояние до истинного соответствия $d_1$ будет существенно меньше расстояния до любого другого кандидата $d_2$:
    $$\frac{d_1}{d_2} < \text{ratio\_threshold} \implies d_1 < 0.75 \cdot d_2$$
  - Если же точка попадает на повторяющийся паттерн (например, одинаковые буквы «о» или «е» в печатном документе или однородный фон), то первый и второй кандидаты будут иметь практически одинаковое расстояние ($d_1 \approx d_2$, отношение $\approx 1.0$). Такие сомнительные точки отбрасываются.
  - Значение порога `0.75` предложено автором алгоритма Дэвидом Лоу: оно отсекает до 90% ложных соответствий, сохраняя свыше 95% истинных.
  - В список `good_matches` добавляются только те объекты `m`, которые успешно прошли проверку.

```python
good_matches = sorted(good_matches, key=lambda x: x.distance)

pct_filtered = (1 - len(good_matches) / len(matches_knn)) * 100
print(f"Количество совпадений до фильтрации: {len(matches_knn)}")
print(f"Количество совпадений после фильтрации по Лоу (порог {ratio_threshold}): {len(good_matches)}")
print(f"Процент отфильтрованных шумов/неоднозначностей: {pct_filtered:.1f}%")
```
- **Строки 10–15:** Расчет численных результатов фильтрации:
  - Совпадений до фильтрации: **126**.
  - Совпадений после фильтрации: **38**.
  - Отфильтровано: **69.8%** неоднозначных связей.

```python
inliers_count = sum(matches_mask)
```
- **Строка 4 (`cv2.findHomography(...)`):**
  - **Матрица гомографии $M$:** обратимое проективное преобразование плоскости в плоскость в однородных координатах:
    $$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} \sim M \begin{bmatrix} x \\ y \\ 1 \end{bmatrix} = \begin{bmatrix} h_{11} & h_{12} & h_{13} \\ h_{21} & h_{22} & h_{23} \\ h_{31} & h_{32} & h_{33} \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$
    Матрица $3 \times 3$ имеет 8 степеней свободы (с точностью до масштаба), поэтому для ее нахождения требуется минимум 4 неколлинеарные пары точек.
  - Флаг `cv2.RANSAC` (**RANdom SAmple Consensus**): итеративный робастный алгоритм:
    1. Случайно выбирает минимальный набор из 4 пар точек.
    2. Вычисляет матрицу-кандидат $M$.
    3. Проецирует все остальные точки и считает ошибку репроекции (евклидово расстояние между спроецированной точкой и ее фактическим положением).
    4. Точки с ошибкой меньше порога объявляются согласующимися (**инлаерами**, inliers).
    5. Процесс повторяется, и выбирается модель с максимальным числом инлаеров.
  - Параметр `5.0` (`ransacReprojThreshold`): максимальная допустимая ошибка репроекции в пикселях. Если спроецированная точка отклоняется не более чем на 5.0 пикселей, она признается истинной.
  - **Возвращаемые значения:**
    - `M`: матрица гомографии $3 \times 3$ типа `float64`.
    - `mask`: бинарный столбец размера $(N, 1)$, где 1 означает инлаер, а 0 — выброс (outlier).
- **Строки 5–6:**
  - `mask.ravel().tolist()`: уплощает массив маски в одномерный список чисел `[1, 1, 0, 1, ...]`.
  - `sum(matches_mask)`: подсчет количества подтвержденных инлаеров. В нашей работе из 38 точек **21 точка признана строгим инлаером**.

```python
    flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS
)

img_localization = cv2.drawMatches(img1, kp1, img2_detected, kp2, good_matches, None, **draw_params)

show_image(img_localization, 'Локализация логотипа на документе (гомография и инлаеры RANSAC)', figsize=(16, 8))
```
- **Строки 15–20:** Словарь параметров отрисовки сопоставлений:
  - `matchColor=(0, 255, 0)`: зеленый цвет для соединительных линий между кадрами.
  - `singlePointColor=None`: одиночные ключевые точки без пар не подсвечиваются.
  - `matchesMask=matches_mask`: **ключевой параметр**. Передает бинарную маску RANSAC. Отрисовываются **только те линии, где значение маски равно 1 (инлаеры)**. Оставшиеся 17 выбросов скрываются.
  - `flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS`: подавляет отрисовку неиспользуемых точек.
- **Строка 22:** Вызов `cv2.drawMatches` с распаковкой словаря `**draw_params`. На сцену `img2_detected` уже нанесена зеленая рамка, а сверху накладываются линии 21 подтвержденного инлаера.
- **Строка 24:** Финальный вывод локализованного объекта. Результат: логотип четко найден, обведен по контуру, подтверждая абсолютную надежность разработанного алгоритма.
